### [Heading1] 1. Executive Summary
M. A. Sarees is a well-established Banarasi silk manufacturer, wholesaler, and retailer based in Varanasi (C 15/345-A-1-A, Lallapura, Varanasi 221001, U.P.). The business currently operates through offline channels and word-of-mouth referrals. This PRD defines the complete specification for a professional website integrated with an AI-powered system that will:
Establish a strong digital presence for M. A. Sarees
Serve B2C retail customers with product discovery and WhatsApp ordering
Serve B2B wholesale buyers with inquiry management and catalog access
Deploy an AI Saree Advisor that helps customers find the right products
Automate lead capture, WhatsApp follow-up, and wholesale inquiry routing
Enable business owners to manage content and leads without technical knowledge
The expected outcome is a 3x–5x increase in online inquiries, expansion of wholesale buyer reach beyond Varanasi to pan-India, and significant reduction in time spent manually responding to repetitive customer queries.

### [Heading1] 6. AI System — Complete Specification
The AI system is the most technically distinctive feature of this project. It consists of three interconnected components that together create a fully automated customer engagement layer.
### [Heading2] 6.1 AI Saree Advisor (Website Chatbot)
### [Heading3] Overview
An AI-powered chatbot embedded on the website that helps customers discover the right saree/product based on their requirements. Powered by Anthropic Claude API (claude-sonnet-4).
### [Heading3] System Prompt Design
AI SYSTEM PROMPT (for Claude API):
You are 'Razia', a friendly AI assistant for M. A. Sarees — a Banarasi Silk Factory in Varanasi. You speak in simple Hindi-English mix (Hinglish). Your job is to help customers find the perfect saree, answer questions about products, and connect them to the owners via WhatsApp.
RULES: 1) Always be warm and respectful. 2) Ask about occasion, budget, and preference before recommending. 3) Recommend products from our catalog only. 4) Always end with WhatsApp CTA. 5) For pricing: quote ranges (exact prices change). 6) For wholesale: collect name, city, quantity, then forward to team. 7) NEVER make up products not in catalog.
### [Heading3] Conversation Flow
Greeting → Ask occasion (Wedding / Festival / Daily / Gift / Wholesale)
Based on occasion → Ask budget range
Ask fabric preference (Pure Silk / Georgette / Tissue / No Preference)
Show top 3 matching products with WhatsApp order link
If user wants more → ask next filter or offer to connect with owner
Capture name + phone at end of conversation for lead database
### [Heading3] Quick Reply Buttons (Persistent)
'Wedding Saree Chahiye' → triggers wedding flow
'Wholesale Inquiry' → triggers B2B flow
'Price Puchna Hai' → price range info
'WhatsApp Pe Baat Karo' → opens WhatsApp
'Catalog Dekhna Hai' → navigates to catalog page

### [Heading2] 6.3 WhatsApp AI Auto-Reply System (Phase 2)
### [Heading3] Technology: Twilio WhatsApp API + Claude API
When a customer messages on WhatsApp (9305453226), the AI system will:
Receive incoming message via Twilio webhook
Classify message intent (product query / price / order status / wholesale)
Generate contextual reply using Claude API
Send reply back via WhatsApp within 30 seconds
If complex query → alert owners on a separate WhatsApp group
### [Heading3] Auto-Reply Templates (AI-Enhanced)
Product inquiry → AI recommends + shares catalog link
Price query → AI gives range + says 'Exact price ke liye WhatsApp pe message karein'
Wholesale → AI sends MOQ info + collects business details
Order status → Owners notified to reply manually
Unknown → 'Aapka message hamare team tak pahunch gaya, hum 1 ghante mein reply karenge'
